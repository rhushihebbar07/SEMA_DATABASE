# AquaDesk V15.8 — Schedule Import Reliability Fix

Fixes duplicate-key failures when importing the official brochure timetable.

## What changed
- Admin Schedule re-reads `schedule_master` immediately before import.
- Existing `source_key` rows are skipped.
- Existing administrator edits are never overwritten by Import All.
- A race between two tabs/imports is handled safely with conflict-ignore retry.
- If all 27 official entries already exist, Import All simply reports that state instead of failing.

No destructive migration is required for this frontend fix. The existing `schedule_master.source_key` unique constraint is intentionally retained.
