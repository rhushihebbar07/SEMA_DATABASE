# AquaDesk V15.7 — Master Timetable

## What changed
- The public Schedule now renders the complete 27-entry Semaphore 2K26 brochure timetable.
- The Super Admin Schedule module is now the canonical timetable editor.
- Every brochure entry can be edited: title, linked competition event, date, start/end time, venue and display order.
- Registration & Breakfast, Inaugural Ceremony and Valedictory Ceremony are editable even though they are not competition events.
- The Competition Events view groups every event's timetable slots.
- `schedule_master` is the canonical editable table. `event_schedule` remains available for operational/legacy attendance schedules.
- If `schedule_master` is not yet installed, the public site still falls back to the brochure timetable so the public page does not go blank.

## Supabase setup
Run `supabase-schedule-master.sql` in the Supabase SQL Editor once.

The seed uses `ON CONFLICT DO NOTHING`, so rerunning the migration does not overwrite administrator edits.

## Recommended workflow
1. Run the migration.
2. Open Super Admin → Schedule.
3. Click **Import all 27** if any entries are still marked BROCHURE.
4. Edit any entry and save.
5. Refresh the public Schedule page. It will read from the master timetable.
