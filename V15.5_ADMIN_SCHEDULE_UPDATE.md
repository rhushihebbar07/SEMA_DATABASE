# V15.5 Admin Schedule Update

## Admin Schedule
- Reworked the Super Admin schedule manager into a mobile-first command centre.
- Groups the live database timetable by Day 01 / Day 02.
- Adds a Competition Events view that shows all official event workspaces.
- Shows live schedule count, venue and coordinator references together.
- Uses official Semaphore 2K26 display names while retaining database IDs for edits.
- Keeps Edit/Delete actions for live `event_schedule` rows.
- The schedule edit modal shows the selected event's coordinator reference before saving.
- Events without database rows are clearly marked `NO DB SLOTS` instead of pretending that brochure reference data is live.

## Event Editor
The existing V15.3 event editor remains the authoritative place to maintain:
- event name and description
- coordinator names and phone numbers
- rules/details
- all linked `event_schedule` rows
- official brochure schedule reference

## Mobile-first
The new admin schedule UI uses stacked cards and touch-sized controls on small screens, while preserving a two-column event overview on larger screens.
